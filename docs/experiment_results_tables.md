# 실험 결과 비교 테이블 (2026-07-17, rev3 지도 반영)

Instance_1 10씬, all-query-view mIoU (최종 R_change를 25개 query pose 전부에서
렌더해 GT 25장과 비교). 집계 스크립트 없이 재현하려면: §1–2는
`experiments/paslcd_nbv_results.csv`, §3–4는
`experiments/{oracle_search_results,all25_repeats}.csv`에서 계산.
노이즈 전제(배치 간 시프트, 선택 민감도, fusion 카오스)는
`budgeted_view_findings.md` §1 참조.

## 1. 예산 곡선 — uniform K장 vs all-25

| K | mIoU | all-25 대비 |
|---|---|---|
| 2 | 0.4066 | 77.7% |
| 3 | 0.4579 | 87.6% |
| 5 | 0.4931 | 94.3% |
| 8 | 0.5008 | 95.8% |
| 10 | 0.5115 | 97.8% |
| 15 | 0.5169 | 98.8% |
| 25 (all) | 0.5230 | 100% |
| **oracle-5 (rev3)** | **0.5857** | **111.8%** |

uniform은 K=5에서 이미 94%를 회수하지만, 잘 고른 5장은 25장 전부를 +11.8%
넘어선다 — 상한은 "all-25"가 아니라 그 위에 있다.
