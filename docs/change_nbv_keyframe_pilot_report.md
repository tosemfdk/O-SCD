## Pilot judgment (spec §13, 3-seed 평균 기준)

  Porch 0.4465→0.5255). **주 실패 원인은 frame-0 고정 seed였고, 기존 4차
  criterion(의심 재관측 + 3×3 방향블록)은 유효하다** (해석 A).
- [x] **판정 2 △ — kf_g_dir은 실패 3씬을 전부 회복하지만(3/3) Zen(0.5147→0.3183)과
  Playground(0.4072→0.3400)를 붕괴시킨다.** global context는 *seed 선택*에는
  유효하나, greedy 전 라운드의 주 신호로 쓰면 R_global의 오신호(all-25 자체가
  약한 씬: Playground all-25=0.3583)가 그대로 전파된다 (해석 F 부분 성립).

### 해석과 결론

1. **이번 사이클의 실질 발견 = seed 자유화.** global score로 첫 프레임만 고르고
   이후를 4차 criterion에 맡긴 kf_l_dir_gseed가 유일하게 uniform·4차를 동시에
   넘었다 (지도 백분위 19.5%→37.7%). 실패 3씬의 공통 원인이 frame-0 고정임이
   실측으로 확정됐다.
2. **global/local mask 성분(g·gl·gu·glu)은 seed 이후 라운드에서는 해롭다.**
   R_global이 약한 씬(Playground: all-25가 uniform보다 낮은 씬)에서 오신호를
   전파하고, sigmoid soft mask의 평탄함(현 current_map 구현 노트와 일치)이
   방향 블록의 변별력을 희석한 것으로 보인다.
3. **Playground 경고**: 유일하게 모든 kf_*가 4차보다 나빠진 씬. oracle 조합
   (0,4,19,20,21)에 frame 0이 포함된 — frame 0이 실제 앵커인 — 씬에서는 seed
   자유화가 소폭 손해다. 평균 이득이 훨씬 크므로 방향은 유지.
4. 선택 비용: R_global 빌드 ~30s + 선택 ~44s/씬 (V100 1장). 전 과정 GT-free,
   claim scope는 offline_pool_keyframe_selection으로 기록됨.

## 판정

1. **10씬 평균에서는 4차와 동률** (0.4872 vs 0.4869; 백분위는 4차가 27.0% >
   gseed 24.5%). pilot의 +0.035는 실패 3씬 편중 씬셋의 효과였다.
2. **상보적 win/loss 구조가 핵심 발견**: gseed는 4차의 실패 3씬을 전부
   크게 회복(+0.06~+0.10)하지만, 4차가 잘하던 씬에서 잃는다(6씬, 최대
   Lunch_room −0.094). frame 0이 무해/유익한 seed였던 씬에서는 global
   seed가 오히려 더 나쁜 출발점을 고른다.
3. anchor overlap도 같은 구조: 4차 0.83 vs gseed 0.30 — gseed는 앵커를 덜
   잡는 대신 독성 seed를 피하는 방식으로 이긴다.
4. **다음 후보는 seed guard(조건부 자유화)**: frame 0의 global rank가 하위권
   일 때만 global seed로 교체하고, 상위권이면 frame 0 유지. 실패 3씬 이득
   (+0.24 합)을 지키면서 성공 씬 손실(−0.25 합)을 줄이는 게 목표.
   (진단 근거: gseed의 first frame이 frame 0이었던 경우는 10씬 중 1씬뿐.)
